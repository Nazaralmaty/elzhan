## Облако vs Mac (что подменено)

- `engine/browser.js`: на Linux — Chromium Playwright (`/opt/pw-browsers/...`), swiftshader вместо Metal.
- `cam.sh` / `matte.py` / `gesture.py` / `blurfaces.py` — macOS Vision, в облаке не идут. Дубль — `work/prep_take_cloud.sh`
  (кроп по плану, без матта — спеке матт не нужен). `qa/face.json` нет → гейт головы мерить глазами по кадрам.
- whisper / Scribe недоступны (huggingface.co, api.elevenlabs.io закрыты сетью окружения).
- `build.sh` использует `stat -f %z` (macOS) и `videotoolbox` — на Linux поправить перед сборкой мастера.
